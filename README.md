# pi2-indicadores-seguranca-publica
Mapa de Indicadores de Segurança Pública (PI - PJI240).

Descrição Geral: O projeto é um site interativo que consome dados abertos do governo sobre criminalidade para apresentá-los de forma geográfica e visual à comunidade externa.

Como Executar o Projeto: Um pequeno passo a passo de como clonar o repositório, ativar a venv, instalar as dependências (pip install -r requirements/local.txt) e rodar o comando python manage.py runserver.
